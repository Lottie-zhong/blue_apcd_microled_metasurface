# R2-4D2 Proxy Limitations

This is a corrected Python-only TMM/STACK-style proxy informed by negative FDTD samples. It still cannot model finite-aperture dipole emission, source-position coupling, or full Lumerical FDTD behavior. Shortlisted candidates require R2-4D3 setup-only FSP generation and R2-4D4 x-line x-dipole FDTD scout before any source-module claim.
