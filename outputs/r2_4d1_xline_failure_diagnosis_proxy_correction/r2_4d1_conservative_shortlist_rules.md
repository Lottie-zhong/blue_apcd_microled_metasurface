# R2-4D1 Conservative Shortlist Rules

Only generate setup-only FSPs when all first-pass rules are met:

- proxy peak_abs_angle_deg <= 5 preferred, <= 7 maximum for the first shortlist.
- proxy angular_FWHM_deg <= 15.
- proxy normal/offaxis ratio is very high only because off-axis absolute response is low.
- integrated 20 to 60 deg off-axis response is below a strict threshold.
- normal-window integrated response exceeds a minimum threshold.
- no strong 30 to 40 deg resonance signature.
- shortlist includes different cavity families, not only repeats of one failure family.
