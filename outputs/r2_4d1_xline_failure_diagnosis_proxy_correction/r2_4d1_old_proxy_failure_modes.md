# R2-4D1 Old Proxy Failure Modes

- R2-4B proxy normal/offaxis is not predictive for x-line x-dipole FDTD normal/offaxis.
- Peak angle and FWHM alone are insufficient. A narrow lobe can be a bad off-axis lobe.
- Candidates must be rejected when normal-window power collapses, even if peak_abs and FWHM look acceptable.
- The old proxy underweighted absolute 20-60 deg response, 30-40 deg resonances, finite-aperture effects, and outcoupling risk.
