# PW energy validity contract

Use physical complex E/H fields and flux-normalized modal powers. Report R(lambda), T(lambda), all retained propagating diffraction-order efficiencies, target +1 efficiency, and closure. Let A(lambda) contain actual modeled absorption/material loss; do not set A=0 by assumption. Proposed admission tolerance is `|1 - (R + T + A)| < 0.01` at each wavelength after native readback and reference-plane validation.
